# 📖 My English Vocabulary App

> **Tkinter/CustomTkinter 기반의 개인 맞춤형 대용량 영어 단어장 프로그램**
> 수동 단어 관리부터 CSV를 활용한 대량 마이그레이션, 미니 퀴즈 및 실전 100문제 테스트 모드까지 지원하는 스마트한 학습 플랫폼입니다.

---

## 🚀 프로젝트 개요
이 프로젝트는 개인의 영어 학습 효율을 극대화하기 위해 다단계로 개발된 데스크톱 애플리케이션입니다. 데이터 관리가 용이한 JSON 포맷을 베이스로 하며, 세련된 다크 모드 UI와 구글 TTS(Text-to-Speech) API를 연동하여 시각·청각적 학습을 동시에 제공합니다.

---

## ✨ 주요 기능 (1~2단계 완료)

### 📌 1단계: 단어장 기본 아키텍처 및 미니 퀴즈
- **CRUD 단어 관리:** 단어, 한국어 뜻, 영어 예문 및 예문 해석을 실시간으로 추가, 수정, 삭제, 검색(`KeyRelease` 방식의 실시간 필터링)할 수 있습니다.
- **멀티미디어 연동:** `gTTS` 및 `pygame.mixer`를 활용하여 영어 단어와 예문의 원어민 발음을 즉시 청취할 수 있습니다.
- **미니 연습 퀴즈:** 등록된 단어 풀에서 무작위로 문제를 출제하며, 예문 내 단어 블라인드 처리(`______`) 힌트 기능과 실시간 정답 피드백을 제공합니다.

### 📌 2단계: 대량 데이터 동기화 및 실전 테스트 모드
- **CSV/엑셀 일괄 연동:** 외부 대용량 단어 데이터(CSV)를 버튼 하나로 내포된 `words.json` 데이터베이스에 병합(Merge) 및 동기화합니다.
- **💯 100문제 실전 테스트 모드:** - 저장된 단어 중 최대 100개를 무작위 셔플링하여 시험을 빌드합니다.
  - 실제 시험 환경과 유사하게 실시간 피드백을 제한하고 묵묵히 정답을 기록합니다.
  - 시험 종료 후 백분율 점수 환산 및 등급별 성적표 리포트를 시각적으로 연출합니다.
- **코드 모듈화(Refactoring):** 스파게티 코드가 되는 것을 방지하기 위해 프로그램 구조를 백엔드 데이터 엔진(`data_manager.py`), UI 프레임 컴포넌트(`screens.py`), 메인 컨트롤러(`main.py`)로 완벽히 분리하여 유지보수성을 극대화했습니다.

---

## 🛠️ 기술 스택
- **Language:** Python 3.x
- **UI Framework:** CustomTkinter (Tkinter 확장 GUI 라이브러리)
- **Audio & TTS:** gTTS (Google Text-to-Speech), Pygame (Mixer 모듈)
- **Data Format:** JSON, CSV
